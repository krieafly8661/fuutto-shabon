# ふーっと、しゃぼん

マイクに息を吹きかけて、シャボン玉をふくらませるブラウザゲーム。

## 遊び方

- 右のメーターの**緑の帯**に息の強さを合わせると、玉がふくらむ。赤の帯（強すぎ）が続くと割れる。
- 玉が大きくなるほど、緑の帯はせまくなり、風のようにゆれる。
- 膜はふくらむほど、時間がたつほどうすくなる。うすくなると色が変わり、**黒っぽくなったら割れる寸前**。
- **吹くのをやめると、玉は空へ飛んでいく。** そのときの直径が記録。割れたら記録なし。

大きさは、ビー玉・サッカーボール・路線バス・東京タワー・富士山など、実物の大きさとくらべて表示されます。

マイクが使えない環境では「指で吹く」を選べます（長押しして、上にずらすほど強い）。Xのアプリ内ブラウザではマイクが使えないことがあるので、Safari や Chrome で開いてください。

## しくみ

- マイクの音は端末の中で強さ（RMS）を測るだけで、どこにも送りません。最初の0.5秒で部屋の静けさを測っています。
- 膜の色は、石けん膜（屈折率1.33）の薄膜干渉を赤・緑・青の3つの波長で計算しています。シャボン玉の上のほうが先にうすくなるので、色は横じまになります。

## 動かし方

`index.html` を開くだけで遊べます。マイクを使うには https か localhost で開く必要があります（GitHub Pages なら https）。

## このゲームを作った理由

2026年10月下旬のXでは、マイクに息を吹いて1000本のろうそくを消す『一息で何歳まで』など、体を使う入力が話題になりました。また、どこまでも規模がふくらむ（牛が光速をこえる、斧が地球を斬る）作品も多く見られました。このゲームはその2つを合わせ、「強すぎても弱すぎてもだめ」という息の加減を遊びの中心にしています。
